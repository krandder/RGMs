# Which fitted RGM levels help a weather controller?

This bridge uses actual `spm_faster_structure_learning` hierarchies in a prediction and control experiment. It complements the known-tree structure-recovery benchmark: here the posterior is over retained **predictive readouts of fitted RGM hierarchies**, conditional on a separate dictionary-building stream. It is not the marginal likelihood of the full variational RGM with every parameter unknown.

A fully observed negative control uses the weather task's transition and reward: weather flips with probability .20, and an open umbrella earns .70, versus 1 if closed and dry and 0 if closed and raining. A second world tests a positive reason to keep a completed path: the next weather equals the previous (lag-two) weather with probability .90. Both are stationary, actions set the umbrella but do not change weather, and a public four-step clock ticks deterministically. The clock makes temporal position observable and limits the number of possible transitions per FSL state; it does not appear in either rain generator or reward rule. These are continuing tasks under the same per-step objective, rather than the phase-one episodic evaluation. Compare gains with a flat two-observation history before attributing any benefit to hierarchical structure.

For each world and seed (11–15), generate independent streams for (i) constructor fit, 512 randomized transitions, (ii) conditional evidence, 384 randomized transitions, (iii) held-out forecast scoring, 2,048 randomized transitions, and (iv) closed-loop control, 4,096 steps of common weather. Never cross stream boundaries when decoding paths. Current observation contains only weather, umbrella and clock. Higher-level features may use completed lower-level transitions; no next observation or path ending after action selection enters a predictor.

Candidates are a flat readout and two FSL grouping-width configurations (`dx` 2 or 3), each with a first-level-only readout or a second-level readout at temporal stride 1 or 2. All non-flat models are fitted on the dictionary stream only. Use the true returned likelihood, transition and parent-index tables. Decode columns from their observation support, preserve unmatched observations/paths as unknown, and use only causal, completed windows for higher-level states. Give equal prior mass to configurations within retained depth and prior depth mass proportional to exp(−depth). If a configuration cannot be constructed, report the exception; do not replace its structure under the same label. Report how many different feature partitions the configurations actually induce. A second nominal depth with no distinctive contexts is not evidence for a meaningful second level.

Every candidate uses a Beta(1/2,1/2) row for next-rain probability given current rain, primitive action, and its chosen feature context. Integrate each row exactly with the beta function. Unseen rows predict 1/2. Compare the exact discrete posterior on the seven *configurations* with samples from an acyclic GFlowNet trained by local flow conservation and terminal rewards. The sampler sees terminal rewards only on visits. Use 512 trajectories with 35% uniform exploration, learning rate .4, and report intermediate checkpoints, wall time, calls/unique rewards and 8,192 final draws. An exact seven-candidate normalization is a necessary speed baseline. No speed advantage is presumed.

Compare Bayesian model averaging using the empirical GFlowNet masses, exact model averaging, flat Markov, flat two-observation history, a fixed two-level FSL readout and the known generator. Measure held-out negative log predictive probability and mean return from each method's own closed-loop actions. Predict action-specific probability of rain; choose the umbrella action maximizing that action's predictive reward. Include per-seed scores, paired differences and common-weather oracle results. These checks distinguish coding fidelity, posterior approximation, forecasting, and control. The known-tree study, not this experiment, supplies a ground-truth level count. No outcome criterion depends on the sign of a measured result.

Numerical amendment after the first run: Some fitted mixtures put forecasts at or very close to the decision boundary (.30). Rerun all seeds with ties within 1e-12 going to the closed action. Preserve the original strict rule and a 1e-5 tolerance as sensitivity estimates, including counts near the cutoff on each policy's own path. These thresholds were not preregistered; interpret a return difference that depends on them as sensitivity to the decision boundary. Forecast and posterior scoring are unchanged.
