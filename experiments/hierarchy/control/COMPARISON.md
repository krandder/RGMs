# Equal returns did not mean identical policies

Removing the hierarchical options changed 39 of 90 policy tables but no expected return. A primitive feedback optimum can match or improve on any fixed open-loop macro *in the fitted model*: the first primitive is available and the feedback policy can condition later actions on observed states. Two equally valued actions in the fitted model can have different true-world returns. The 90 equal true-world returns are a measured result, not a theorem about all environments.

At 4,096 training transitions, the median fit-plus-planning wall times over ten seeds were 59.09, 46.83 and 32.83 seconds for the grounded adapter (interception, key and door, and weather). The flat empirical planner took .041, .052 and .053 seconds respectively and attained the same returns. The timings include policy construction on a shared CPU; lookup latency alone would miss this difference.

The [saved encodings](artifacts/run-v1/representation-collisions.json) show which distinctions the memoryless upper-level projection discarded. All 30 interception fits merged every otherwise equal state pair differing only in ball position, direction, or paddle position. All 30 weather fits merged rain and umbrella distinctions. At the final budget all ten corridor fits merged key/no-key at each position. These are properties of this fitted projection on the complete state alphabet. They do not show that the full native temporal agent lacks those distinctions. The [instrumented compression check](artifacts/compression-diagnostic.json) traced one mechanism in a single interception fit.

The [protocol](PROTOCOL.md) was committed to the fork before the measured run and its criteria were unchanged. An earlier software smoke run on seed 101 at 256 transitions preceded the final implementation. Fixes included path-decoder handling and a terminal sink for pymdp. The smoke measurements are not additional replicates. The subsequent matched-decoder check was post hoc and is labeled in [the main report](RESULTS.md). Each file in [the measured run](artifacts/run-v1) records the policy, exact return, and the timing components used above.
