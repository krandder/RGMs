# Do learned action sequences help when search is limited?

Exploratory follow-up registered after the control adapter smoke test. With an exact finite-horizon planner and all primitives present, a fixed open-loop option cannot improve the optimal fitted-model value. Here each method may instead score only two or eight full action strings per possible first primitive. This is a test of where to spend a small search budget; the results of this experiment have not been inspected.

Use the control study's deterministic five-position key/door corridor, reward, horizon eight, and a uniform random log of 4,096 steps for each new seed 201–210. All methods share the same estimated primitive transition/reward model and learned terminal flags. A full empirical-model dynamic program provides a ceiling in that model. Separately evaluate the selected primitive policy using the true environment for exact expected return. Do not generalize this diagnostic to stochastic planning or discounted tasks.

For every observable state and remaining time, propose K complete strings for each of the three possible first actions. The first string repeats that action; for K−1 other strings, draw subsequent chunks at the states reached in the fitted model, with 25% chance of a uniform primitive, else a uniform sequence from the current library (back off to a primitive when empty). Stop at the horizon or terminal. The corridor's fitted rows, with unseen rows self-looping, are deterministic. Replan after each primitive. Choose the best predicted return, breaking ties by smallest first action. Share uniforms by (seed, state, remaining steps, first action, candidate, time); use nested K. The planner does not see the environment in construction or search.

Compare libraries: (1) FSL options from the phase-one adapter, (2) cyclic reassignment of nonempty or empty libraries among sorted encoded contexts, (3) pooled log sequences, (4) raw-state log sequences with no hierarchy, and (5) uniform primitives. Flat libraries use the same episode-safe windows of 2 and 4, 32 most frequent, lexicographic ties. Report contexts, option sizes, sampled candidates, primitive model steps, construction and planning wall times; consider full DP cost on these tiny worlds. Cyclic reassignment can be inert when contexts collide; record that. Use means and every seed-paired difference, no tuning or superiority gate. A performance improvement over uniform search alone is insufficient to credit hierarchy.
